# Arka Roy website

A simple static site ready for GitHub Pages.

## Files
- `index.html` — Academic page
- `personal.html` — Personal/travel page
- `style.css` — Shared styles
- `CNAME` — Custom domain (`www.arkajyotiroy.com`)

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `arkajyotiroy-site`).
2. Upload these three files to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. The included `CNAME` file sets the custom domain to `www.arkajyotiroy.com`. In GitHub Pages settings, confirm that domain and then update the domain DNS records to point to GitHub Pages. Make the DNS change only after the GitHub preview is working.

No build system, Jekyll theme, or package installation is required.
